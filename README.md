# Mokgadi Beanies - SQL Database Project

## Overview

This project is a relational database developed for a fictional beanie business, Mokgadi Beanies.

The database is designed to manage information about customers, products, orders, payments and other related data.

## Technologies Used

- MySQL
- SQL
- Relational Database Design

## Database Components

The project contains SQL scripts for:

- Customer information
- Product information
- Orders
- Order items
- Payments
- Customer interests
- Data insertion
- Database creation

## SQL Concepts Demonstrated

- Database creation
- Table creation
- Primary keys
- Foreign keys
- Relationships between tables
- Data insertion
- SQL queries
- Relational database design
